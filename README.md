# 🎓 IT & AI News Mentor Bot

Умный Telegram-бот, который собирает свежие новости из мира IT, нейросетей и кибербезопасности и превращает их в персональную обучающую программу (Reverse Learning).

---

## 🚀 Возможности

1. **Автоматический мониторинг источников:**
   - **Хабр (Хабы ИИ, Инфобезопасность, Разработка)** — проверенные русскоязычные статьи.
   - **The Hacker News** — мировой первоисточник по кибербезопасности и эксплоитам.
   - **BleepingComputer** — анализ инцидентов, малвари и уязвимостей.
   - **TechCrunch AI** — тренды индустрии и новые модели.

2. **Обработка через Gemini AI:**
   - **Краткая выжимка (TL;DR):** 2–3 понятных предложения без воды и маркетинга.
   - **Что изучить (Концепты):** 2–3 фундаментальных термина для студента с объяснением на пальцах.
   - **Промпт в 1 клик:** готовый вопрос для ChatGPT/Gemini/Claude, чтобы закрепить тему.
   - **Перевод на русский язык** даже для зарубежных источников.

3. **Расписание и кнопка по требованию:**
   - Утренний дайджест: **09:00** (под кофе).
   - Вечерний дайджест: **19:00**.
   - Кнопка **«☕ Свежий дайджест»** в любой момент.
   - Защита от дублей: локальная база данных SQLite гарантирует, что новость никогда не повторится.

---

## 🛠 Запуск на Windows

1. Дважды кликните по файлу `run_bot.bat`.
2. Откройте в Telegram вашего бота `@it_ment_news_bot` и нажмите `/start`.
3. Нажмите кнопку **«☕ Свежий дайджест»**!

---

## ⚙️ Настройки в `.env`

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота.
- `GEMINI_API_KEY` — бесплатный ключ Google Gemini API.
- `MORNING_HOUR` — час утренней рассылки (по умолчанию `9`).
- `EVENING_HOUR` — час вечерней рассылки (по умолчанию `19`).
- `NEWS_PER_DIGEST` — сколько новостей выдавать в одной порции (по умолчанию `4`).
